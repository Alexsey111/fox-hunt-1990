# Выпуск 1.0.8 после публикации в RuStore

Черновик плана. Делать, когда карточка пройдёт модерацию и появится публичный адрес вида
`https://www.rustore.ru/catalog/app/ru.foxhunt.game` (проверить: открывается и показывает
наше приложение).

## Что уже подготовлено (в main, но ещё не выпущено)

- **Разрешение INTERNET убрано из манифеста.** Проверено отдельным прогоном CI: сборка без
  этого разрешения ставится, запускается и рисует поле (снимок —
  `ru-store/проверка-apk-без-разрешений.png`). Для WebView с `WebViewAssetLoader` сеть не
  нужна, внешние ссылки открывает браузер, у которого свои разрешения.
- **Планшетная вёрстка:** ширина поля ограничена высотой окна
  (`@media (min-width: 561px) and (max-height: 940px)`), поэтому на 1024×768 и 1280×800
  доска видна целиком, без прокрутки.
- **Место под ссылку на RuStore** в подвале и в правилах: `LINKS.rustore` в
  `assets/app.js`, пока пустая строка — пункт скрыт, битых ссылок нет.
- **Описание для карточки** переписано (`ru-store/описание-полное.txt`): вместо «нет
  интернета» точная формулировка про работу без сети и внешние ссылки.
- **Планшетные скриншоты** 1600×2560 — `ru-store/скриншоты-планшет/`.

## Порядок выпуска

1. Вписать адрес карточки:
   ```js
   rustore: 'https://www.rustore.ru/catalog/app/ru.foxhunt.game',
   ```
   в `LINKS` (`assets/app.js`).
2. Поднять версию: `package.json` → `1.0.8`, в `sw.js` имя кэша → `fox-hunt-1.0.8`
   (сборка проверяет, что они совпадают).
3. `npm test` (53 теста), `node tools/build-web.js`.
4. `npm run dist` — установщик и portable. Проверить: `dist-desktop\oxota-na-lis-1.0.8-portable.exe --selftest` → код 0.
5. Коммит и push, затем Actions → workflow «android» → Run workflow (APK + проверка на эмуляторе).
6. Создать релиз `v1.0.8` и положить: `oxota-na-lis-setup-1.0.8.exe` + копию под постоянным
   именем `oxota-na-lis-setup.exe`, portable (тоже с копией), `oxota-na-lis-1.0.8.apk` (CI
   прикладывает сам по тегу) + `oxota-na-lis.apk`, `dist-web.zip`.
7. Проверить ссылки `releases/latest/download/…` заголовком `Content-Length`.
8. В RuStore: «Загрузить версию» → APK 1.0.8 → раздел «Что нового?»:

   > Убрали разрешение на доступ в интернет — приложение теперь вообще не запрашивает
   > разрешений. Поле удобнее на планшетах: доска целиком помещается в экран, без прокрутки.
   > В правилах появилась ссылка на эту карточку.

9. В карточке обновить: полное описание (из `ru-store/описание-полное.txt`), блок
   «Скриншоты для планшетов» (три снимка), при желании — FAQ (`ru-store/FAQ.txt`).
10. В `privacy.html` заменить абзац про разрешения: приложение 1.0.8 их не запрашивает.
11. Проверить на живом адресе: подвал сайта, ссылка «Приложение в RuStore», офлайн-запуск.

## Чего не делать

- Не менять ключ подписи: обновление другим ключом не встанет поверх установленной версии.
  Ключ — `C:\Users\Worker\.agent-secrets\foxhunt-apk\`.
- Не понижать версию: RuStore требует, чтобы номер новой версии был больше предыдущего.
- Не убирать постоянные имена файлов из релиза: на них держатся ссылки в игре.
