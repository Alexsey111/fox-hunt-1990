## 2. Куда развивать

### Ветка A. Публикация веба — 1 сессия, денег не требует

Задача: чтобы ссылку можно было дать человеку в РФ и она открылась.

1. Выбрать хостинг, доступный из РФ (проверено с этой машины):
   - Netlify — доступен, drag&drop папки, HTTPS из коробки, бесплатный тариф;
   - Cloudflare Pages — доступен, бесплатно, быстрее в РФ;
   - Vercel — доступен, бесплатно.
2. ~~Подготовить PWA-обвязку~~ — **сделано 28.10.2026**: `manifest.json`, иконки
   192/512/maskable и apple-touch, `sw.js` с офлайн-кэшем, кнопка «Установить»
   (`beforeinstallprompt`), мета-теги. Сборка для хостинга — `npm run web` →
   `dist-web/` (12 файлов, 435 КБ, плюс `_headers`). Проверено офлайн в браузере
   и на собранной папке: см. `ЗАМЕТКИ-СЛЕДУЮЩАЯ-СЕССИЯ.md`, §1.10.
3. Выложить, проверить: игра стартует, сохранения работают, ссылка открывается
   с телефона.

Что нужно от владельца: аккаунт на выбранной площадке (регистрация через GitHub,
минута) либо 5 минут на перетаскивание папки в Netlify Drop. Папка готова:
`C:\Users\Worker\Desktop\охота-на-лис\dist-web`.

### Ветка B. Десктоп-дистрибуция — 1 сессия

1. Подпись кода: без неё SmartScreen показывает «неизвестный издатель» и часть
   людей не запускает. Сертификат для физлица — от 15–30 тыс. ₽ в год
   (проверять у продавца: нужен именно code signing). Решение владельца.
2. Автообновление (electron-updater) — тогда правки доезжают до игроков сами.
   Имеет смысл только вместе с подписью и хостингом обновлений.
3. Страница загрузки: та же, что веб (Netlify/Cloudflare) — один адрес,
   на нём кнопки «играть в браузере» и «скачать для Windows».
4. Раздача: ссылка на странице плюс пара постов (Хабр, Пикабу, профильные
   форумы). itch.io и Steam для РФ сейчас плохи: itch.io из этой сети не
   открывается, Steam требует $100 и оплату из-за рубежа.

### Ветка C. Android и RuStore с рекламой — 3–5 сессий

Это единственная ветка, которая может приносить деньги, и самая затратная.

1. Сборка приложения: Capacitor или TWA-обёртка вокруг той же статической игры.
   Локально нужны JDK и Android SDK (несколько гигабайт), либо сборка в GitHub
   Actions — тогда на машине ничего ставить не надо.
2. Аккаунт RuStore: бесплатный, выплаты в рублях, требования к приложению
   (иконки, скриншоты, описание, политика конфиденциальности).
3. Реклама: сеть RuStore или Яндекс. AdMob для российского издателя закрыт.
   Точки показа — за подсказку и между партиями (не в момент раздумья).
4. Google Play — только при наличии легального зарубежного аккаунта и карты;
   оплата аккаунта ($25) из РФ не проходит, обходные схемы нарушают условия.

### Ветка D. Игровое развитие — по желанию, 1 сессия на пункт

- Ежедневные задачи с серией и «стриком» уже есть; можно добавить достижения
  (первая победа, 19 ходов, все режимы).
- Шаг перебежки в гоне — **проверено замером 28.10.2026 и отменено**: даёт +9…38 %
  ходов при шагах 2–3, тогда как интервал перебежки сильнее в 2–3 раза, а в конфигурации
  «все» работает наоборот. Разбор — `docs/шаг-перебежки.md`. Если гон перекалибровывать,
  начинать с интервала, а не с шага.
- Таблица рекордов по seed — без сервера не сделать; минимум нужен бэкенд.
- Обучение для новичка: короткая партия 4×4 с подсказками на каждом шаге.
- Ещё один режим «по описанию 1990»: только индикатор, поле 10×10, 8 лис,
  но с журналом пеленгов как в оригинале.

### Ветка E. Онлайн-дуэли — от 1 сессии, зависит от варианта

Логика игры подходит для дуэли идеально: партия полностью определяется сидом, ходы
независимы, а результат сравним одним числом — количеством ходов (и временем).
Поэтому «сеть» здесь нужна не для игры, а только для обмена результатами.

Четыре варианта, от дешёвого к дорогому:

| Вариант | Что даёт | Инфраструктура | Оценка |
|---|---|---|---|
| Вызов по ссылке | друг открывает ваш сид, играет, видит сравнение | нет | 1 сессия |
| Один экран (hot seat) | двое играют по очереди на одном устройстве | нет | 1 сессия |
| Комната в реальном времени | общий старт по сигналу, финиш фиксируется | сервер | 2–3 сессии |
| Рейтинг и турниры | общий лидерборд, сезоны | сервер, аккаунты, античит | 5+ сессий |

**Вызов по ссылке** — это расширение того, что уже есть: игра умеет читать `#seed=…&vs=…`.
Нужно довести до конца: экран «вас вызвали, вот результат соперника», после партии —
сравнение «вы 17, он 19», кнопка «ответить вызовом». Ноль рублей, ноль серверов,
работает офлайн и в десктопе.

**Один экран** — самая недооценённая вещь: две мыши не нужны, игра и так пошаговая.
Экран «игрок 1 / игрок 2», общий сид, каждый делает свои ходы по очереди, результат
сравнивается. Хорошо для семьи и для демонстрации игры кому-то вживую.

**Комната в реальном времени.** Нужен маленький сервер (Node + WebSocket, ~150 строк,
состояние в памяти, без базы): комната на двоих, общий сид, сигнал старта, приём финиша.
Хостинг: свой VPS (уже есть под бота) или Cloudflare Workers + Durable Objects
(домены доступны из РФ, бесплатный тариф покрывает сотни комнат в день).
Это реально, но это первый в проекте сервер — появляется то, что может упасть.

**Рейтинг и турниры** — не начинать. Любой клиентский результат подделывается:
сейчас счёт считает браузер. Для честного рейтинга сервер должен сам пересчитывать
ходы, а значит держать движок, проверять каждый пеленг, хранить аккаунты и модерировать
споры. Это уже другой проект, и он не окупается рекламой.

Рекомендация: сделать вариант 1 и 2 (две сессии, ноль затрат), а комнату — только
если появится живой запрос от людей. Про читерство в отчёте сказать честно: дуэль
по ссылке — для друзей, не для соревнования.

### Ветка F. Десктопные приложения не-игры

Тот же механизм (Electron-обёртка вокруг локальной страницы) подходит для любых
инструментов на Python/AI, которые сейчас отдаются как «запусти скрипт»: обёртка
делает из них exe с окном, иконкой и меню. Ограничение одно — всё, что делает такой
инструмент, должно быть доступно из браузерного слоя; если нужен Python, то это
другая схема (обёртка вокруг локального сервера), и она сложнее.

Что уже готово к переиспользованию: `desktop/main.js` как шаблон окна с меню,
сохранением размера, внешними ссылками и режимами `--selftest`/`--smoke`, скилл
`electron-desktop-wrapper`.

## 3. Деньги: честная арифметика

Реклама в нишевой логической игре даёт мало. Порядок величин для РФ:
1000 активных в день при двух-трёх показах — несколько тысяч рублей в месяц.
Подписка на LLM ($20 ≈ 1600 ₽) требует 2–5 тысяч активных в день.

Что реально может дать больше при малой аудитории:

- платная версия без рекламы (30–100 ₽) — 20 покупок = как 10 тысяч показов;
- донат «поддержать» на странице загрузки;
- для Android — реклама RuStore/Яндекс как эксперимент, а не как план.

### 3.1. Донат и версия без рекламы

- **Донат.** Кнопка «Поддержать проект» в подвале и в окне победы, ссылка на Boosty или
  ЮMoney (оба домена открываются из РФ). Работы — полчаса, обязательств — ноль,
  доход — символический, но он честный и не портит игру.
- **Платная версия без рекламы** имеет смысл только там, где реклама есть, то есть
  в Android (RuStore, встроенные покупки). В вебе и на десктопе рекламы нет по решению
  владельца — продавать «версию без рекламы» нечего. Для выплат в RuStore нужен
  статус (самозанятый или ИП).
- **Что продавать вместо этого**, если захочется: наборы задач сверх ежедневных,
  ранний доступ к новым режимам, «спасибо» на странице загрузки. Всё это требует
  производства контента, а не только кнопки.

Итог: донат — сделать сразу, он ничего не стоит; платную версию — только вместе
с Android и только как «убрать рекламу».

Вывод: рекламу рассматривать как проверку гипотезы, а не как источник денег
на подписки. Если цель — оплачивать LLM и запуск бота, честнее считать, что
проект окупается репутацией и портфолио, а не показом баннеров.

## 4. Юридическая сторона

- Правила и механика игры авторским правом не охраняются; код, вёрстка и графика
  написаны с нуля — претензий по коду быть не может.
- Название и текст статьи 1990 года — не наши. Безопасная формулировка уже стоит
  в шапке и README: авторы правил Ю. Иванов и П. Иртюга, «Наука и жизнь» № 10, 1990.
  В подвале — «Воссоздал и дополнил: Алексей».
- Лицензия кода: сейчас не указана. Для открытого репозитория стоит добавить
  MIT (или оставить «все права защищены», если код не для свободного использования).
- Для магазина приложений понадобятся: политика конфиденциальности (обязательна
  при рекламе), разметка Data safety (что собирает рекламный SDK), возрастной
  рейтинг, экран согласия на персонализированную рекламу для ЕС.
- Реклама в РФ маркируется (ОРД); сети берут часть на себя, но проверять
  требования нужно до запуска, а не после.

## 5. Технический долг и риски

| Что | Почему важно | Оценка |
|---|---|---|
| Нет PWA-обвязки (manifest, service worker, иконки) | без неё нет установки на телефон и офлайна в вебе | ~~сделано 28.10~~ |
| Нет подписи кода | SmartScreen отпугивает при первом запуске | сертификат, деньги |
| Нет автообновления | правки не доезжают до игроков | полдня |
| Нет тестов на локали | тексты проверялись глазами, не автотестами | 2 часа |
| Файлы в репозитории с CRLF | нормализованы через `.gitattributes`, но при правках возвращаются | привычка + `--fix-lf` |
| `win-unpacked` и `build-out2` держатся Windows | остаются пустые каталоги после сборки | уйдут после перезагрузки |
| Портативная сборка не печатает в консоль | `--selftest` на portable проверяется только снимком | известное ограничение NSIS |
| Рекорды только локальные | нет общего лидерборда и «поделиться результатом картинкой» | бэкенд или отказ от идеи |
