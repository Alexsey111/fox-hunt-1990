Политика конфиденциальности

Игра «Охота на лис — 1990 / 2026» · редакция от 28 октября 2026 года

Коротко: игра не собирает, не передаёт и не хранит на серверах никаких персональных данных. Сервера у неё нет. Всё, что создаётся в игре, остаётся на вашем устройстве.

1. Кто и что обрабатывает

Игра работает полностью на устройстве пользователя: в браузере, в установленном веб-приложении (PWA) или в приложении для Windows и Android. Обработчик персональных данных не привлекается, потому что персональные данные не собираются.

2. Какие данные сохраняются

Только внутри устройства, в локальном хранилище браузера или приложения (localStorage):

  • выбранный уровень, вариант игры и оформление;
  • номер партии (случайное число) и сделанные заходы — чтобы можно было продолжить партию;
  • личные рекорды, статистика партий и отметки на поле.

Эти данные не покидают устройство, не отправляются на сервер и не связаны с личностью пользователя. Удалить их можно в любой момент: кнопка сброса настроек в игре, очистка данных сайта в браузере или удаление приложения.

3. Что игра не делает

  • не запрашивает имя, телефон, почту, геолокацию, контакты, камеру, микрофон и файлы;
  • не использует аналитику, трекеры, рекламные и идентификационные SDK;
  • не показывает рекламу и не передаёт данные третьим лицам;
  • не создаёт учётных записей и не требует регистрации.

4. Разрешения приложения для Android

В приложении указано единственное разрешение — доступ в интернет. Оно нужно не игре (она работает офлайн), а системному компоненту, который показывает веб-страницу: без него Android не отдаёт локальные файлы приложения. Никакие запросы наружу приложение самостоятельно не делает.

5. Переходы по внешним ссылкам

В подвале игры и в разделе правил есть ссылки на страницы проекта: репозиторий на GitHub, загрузка версии для Windows и, если она указана, страница добровольной поддержки. Переход по ним открывает внешний сайт, и дальше действуют правила этого сайта. Игра при таком переходе никаких данных не передаёт.

6. Дети

Игра не собирает данные ни от кого, включая детей, и не содержит рекламы, покупок и внешних чатов. Возрастная маркировка — 0+.

7. Изменения политики

Если когда-нибудь появится функция, требующая данных (например, общая таблица рекордов), эта страница будет обновлена до её появления, а в описании игры появится предупреждение.

8. Контакты

Вопросы по игре и по этой политике: issues в репозитории проекта (аккаунт GitHub) — самый быстрый способ связи с автором.

Privacy policy

“Fox Hunt — 1990 / 2026” · revision of 28 October 2026

In short: the game collects no personal data, sends none anywhere and keeps nothing on servers. It has no server at all. Everything the game creates stays on your device.

What is stored

Only on the device, in local storage: the chosen level, variant and theme; the game number and your probes so a game can be resumed; personal bests, statistics and marks on the board. These never leave the device and are not linked to any person. You can erase them at any time by resetting settings in the game, clearing site data in the browser or uninstalling the app.

What the game never does

It does not ask for a name, phone, e-mail, location, contacts, camera, microphone or files; it uses no analytics, trackers or advertising SDKs; it shows no ads; it has no accounts and no sign-up.

Android permissions

The only declared permission is internet access. The game itself works offline — the permission is required by the system web component that renders the page. The app makes no network requests of its own.

External links

The footer and the rules screen link to the project pages (GitHub repository, Windows download, and the voluntary support page when one is listed). Following them opens an external site that follows its own rules. The game transfers nothing on such a click.

Children, changes, contact

No data is collected from anyone, children included; there is no advertising, no purchases and no chat. Age rating 0+. If a feature needing data is ever added, this page will be updated before it ships. Contact: the project issue tracker.
