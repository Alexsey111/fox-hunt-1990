# Если модерация откажет: что отвечать и что исправлять

Читать спокойно: отказ по первой версии — обычное дело, у RuStore в правилах прямо
перечислены основания. Ниже — самые вероятные причины именно для нашей сборки и что
против них есть. Всё это уже лежит в репозитории, ничего заново собирать не нужно.

## 1. «Мобильный сайт в виде приложения»

Правило модерации: *«Запрещается публиковать мобильный сайт в виде самостоятельного
приложения без дополнительной функциональности… WebView-приложения допускаются только при
наличии дополнительной функциональности (например, push-уведомлений, офлайн-режима или
интеграции с возможностями устройства)»*.

Что ответить:

> Приложение не является обёрткой над сайтом. Весь код игры (движок, уровни, разбор
> партий) лежит внутри APK и работает без интернета — в самолётном режиме игра запускается
> и полностью играбельна. Кроме того, приложение использует возможности устройства: печать
> бланка через системный диалог печати Android и системное меню «Поделиться» для ссылки на
> дуэль. Обработка кнопки «Назад» и сохранение партии при повороте экрана тоже на стороне
> приложения.

Доказательства, если попросят: `ru-store/проверка-apk-эмулятор.png` (снимок запущенного
APK), job `smoke` в CI (установка, запуск, снимок), `assets/www/` внутри APK.

## 2. «Приложение не запускается / не выполняет заявленные функции»

У нас есть автоматическая проверка: workflow `android`, job `smoke` ставит APK на
эмулятор Android 30, запускает `ru.foxhunt.game/.MainActivity` и снимает экран. Последний
прогон — успешный. Если модератор пишет об этом, просите указать модель и версию Android:
`minSdk 26` (Android 8.0), `targetSdk 34`.

## 3. «Разрешение не соответствует функциональности»

Разрешение только одно — `INTERNET`. Оно нужно исключительно для того, чтобы по нажатию
пользователя открыть в браузере внешнюю ссылку из правил (исходный код, политика
конфиденциальности). Никаких запросов к сети при запуске и во время игры приложение не
делает: все ресурсы внутри. При желании это подтверждается по `assets/www/` в APK.

## 4. «В описании есть функции, которых нет»

Сверять построчно: в описании заявлены шесть уровней, «Гон», «МК-61», печать бланка,
подсказки, разбор партии, отмена захода, рекорды, два оформления, ru/en. Всё это есть и
проверено. Если что-то из этого модератор не нашёл — присылайте формулировку, поправим
описание, а не приложение.

## 5. «Контакт разработчика не указан»

Поле обязательное: почта, сайт, сообщество ВК или канал МАКС. Почту вписывает владелец в
консоли, в репозитории её держать не нужно.

## 6. «Возрастной рейтинг не соответствует»

0+ у нас потому, что нет ни насилия, ни текста, ни покупок, ни рекламы: только сетка, числа
и правила. Если модератор поднимет рейтинг — это его право, публикации не мешает.

## Порядок действий при отказе

1. Прочитать причину дословно и не спорить с формулировкой — исправлять по существу.
2. Если причина про WebView — отвечать пунктом 1 выше, с приложением снимка экрана.
3. Если причина про контент или описание — править описание (оно лежит в
   `ru-store/описание-полное.txt`), а не APK.
4. Если причина про сборку — пересобрать: `npm run dist` для Windows и workflow `android`
   для APK; версия поднимается в `package.json`, номер сборки (`versionCode`) считается из
   версии автоматически.
5. Повторная загрузка — тем же ключом подписи. Ключ: `C:\Users\Worker\.agent-secrets\foxhunt-apk\`.
   Другим ключом обновление не встанет поверх.
