# Публикация в RuStore

Всё, что нужно положить в карточку, лежит здесь. Регистрация аккаунта — за владельцем
(нужны паспортные данные и почта), загрузка и модерация — в консоли RuStore.

## Что загружать

| Поле карточки | Файл |
|---|---|
| APK | `https://github.com/Alexsey111/fox-hunt-1990/releases/latest/download/oxota-na-lis-1.0.4.apk` (634 КБ, подписан, sha256 `b68bee68…d9675`) |
| Иконка 512×512 | `assets/icons/icon-512.png` |
| Скриншоты телефона | `ru-store/скриншоты/01-поле.png`, `02-правила.png`, `03-мк61.png` (1080×1920) |
| Краткое описание | `ru-store/описание-краткое.txt` (≤ 80 символов) |
| Полное описание | `ru-store/описание-полное.txt` (~2 700 символов) |
| Политика конфиденциальности | `https://alexsey111.github.io/fox-hunt-1990/privacy.html` |
| Категория | Игры → Головоломки |
| Возрастной рейтинг | 0+ |
| Разрешения | только INTERNET (см. privacy.html, раздел 4) |
| Платный/бесплатный | бесплатно, без покупок внутри |
| Контакты | issue-трекер GitHub |

APK собирается в GitHub Actions: Actions → workflow «android» → Run workflow.
Подпись берётся из секретов `ANDROID_KEYSTORE_BASE64` и `ANDROID_KEYSTORE_PASSWORD`
(уже заведены). Ключ подписи сохранён у владельца в
`C:\Users\Worker\.agent-secrets\foxhunt-apk\` — без него обновления не встанут поверх
установленной версии, ключ нельзя терять.

## Шаги в консоли

1. Зарегистрировать аккаунт разработчика (бесплатно), роль «Владелец компании».
2. Приложения → «Добавить приложение» → название «Охота на лис».
3. «Загрузить версию» → тип «Универсальный» → загрузить APK.
4. Заполнить карточку: иконка, скриншоты, оба описания, категория, 0+, ссылка на политику.
5. Отправить на модерацию. Проверка обычно занимает несколько дней.
6. После публикации — прислать ссылку на карточку, впишем её в правила и на страницу
   проекта.

## О чём стоит помнить

- RuStore требует, чтобы APK был подписан; наш подписан схемой v2/v3.
- Для бесплатных приложений без покупок платёжные инструменты и самозанятость не нужны.
- Модерация не любит пустых обещаний: в описании не должно быть функций, которых нет.
  Поэтому про донат написано осторожно — «если захочется поддержать».
- Скриншоты снимались на 1080×1920; если консоль попросит другой размер, снимем заново
  тем же способом (эмуляция 360×640 при DPR 3).
