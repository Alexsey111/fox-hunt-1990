# Публикация в RuStore

Всё, что нужно положить в карточку, лежит здесь. Регистрация аккаунта — за владельцем
(нужны паспортные данные и почта), загрузка и модерация — в консоли RuStore.

## Что загружать

| Поле карточки | Файл |
|---|---|
| APK | `https://github.com/Alexsey111/fox-hunt-1990/releases/latest/download/oxota-na-lis-1.0.5.apk` (638 КБ, подписан, sha256 `f2a13cad…ced489`) |
| Иконка 512×512 | `assets/icons/icon-512.png` |
| Скриншоты телефона | `ru-store/скриншоты/01-поле.png`, `02-правила.png`, `03-мк61.png` (1080×1920) |
| Краткое описание | `ru-store/описание-краткое.txt` (≤ 80 символов) |
| Полное описание | `ru-store/описание-полное.txt` (~2 700 символов) |
| Политика конфиденциальности | `https://alexsey111.github.io/fox-hunt-1990/privacy.html` |
| Категория | Игры → Головоломки |
| Возрастной рейтинг | 0+ |
| Разрешения | только INTERNET (см. privacy.html, раздел 4) |
| Платный/бесплатный | бесплатно, без покупок внутри |
| Контакты | issue-трекер GitHub |

APK собирается в GitHub Actions: Actions → workflow «android» → Run workflow.
Подпись берётся из секретов `ANDROID_KEYSTORE_BASE64` и `ANDROID_KEYSTORE_PASSWORD`
(уже заведены). Ключ подписи сохранён у владельца в
`C:\Users\Worker\.agent-secrets\foxhunt-apk\` — без него обновления не встанут поверх
установленной версии, ключ нельзя терять.

## Шаги в консоли (по официальной инструкции RuStore)

1. Регистрация аккаунта разработчика — сделано. Добавлять приложение может только роль
   **«Владелец компании»** — при самостоятельной регистрации она и есть.
2. **Приложения → «Добавить приложение»** → название (до 30 символов, должно быть уникально):
   `Охота на лис — 1990/2026`.
3. Выбрать приложение → **«Загрузить версию»** → тип **«Универсальный»** → перетащить
   `oxota-na-lis-1.0.6.apk`. Загрузка идёт в два этапа: пока идёт передача файла, страницу
   нельзя закрывать; обработку можно пережить в фоне (кнопка «Сохранить как черновик»).
   Обработанные файлы хранятся 14 дней — за это время версию нужно отправить на модерацию.
4. Заполнить форму версии:
   - **Что нового?** — текст из заметок к релизу (1.0.6: печать через системный диалог,
     системное «Поделиться» для дуэли, работа с Android 8.0 и новее).
   - **Безопасность данных пользователя / разрешения** — приложение не собирает данные,
     единственное разрешение `INTERNET`; ссылка на политику:
     `https://alexsey111.github.io/fox-hunt-1990/privacy.html`.
   - **Информация о приложении** — название, категория «Игры → Головоломки», маркировки
     внутриигрового контента (нет ни покупок, ни рекламы), возрастное ограничение **0+**,
     до 5 поисковых тегов, краткое описание ≤ 80 символов, полное ≤ 4000 символов.
     Минимальная версия Android подтянется из манифеста (у нас 8.0).
   - **Контакты разработчика** — обязательно хотя бы одно поле: почта, сайт, сообщество ВК
     или канал МАКС. Здесь нужна ваша почта: вписать в консоль, в репозитории её держать
     не нужно.
   - **Медиафайлы** — иконка 512×512 (`.png`, до 3 МБ), не менее 3 скриншотов телефона
     (у нас три по 1080×1920, максимум 2160×3840).
5. **«Отправить на модерацию»** (или «Сохранить как черновик» — черновик может быть только
   один). После проверки карточка появляется в каталоге.

## Что важно знать про правила RuStore

- **WebView-приложение допустимо только с дополнительной функциональностью.** В правилах
  модерации прямо написано: «публиковать мобильный сайт в виде самостоятельного приложения
  без дополнительной функциональности» запрещено, а WebView-оболочки «допускаются только при
  наличии дополнительной функциональности (например, push-уведомлений, **офлайн-режима** или
  интеграции с возможностями устройства)».
  У нас есть все три опоры, и в описании это сказано явно: игра целиком лежит внутри APK и
  работает без интернета; печать бланка идёт через системный диалог печати Android; ссылка на
  дуэль отдаётся в системное «Поделиться»; кнопка «Назад» и поворот экрана обрабатываются
  приложением, а не браузером.
- **Минимальная поддерживаемая версия — Android 8.0.** Было 7.0 (`minSdk 24`), в 1.0.6
  поднято до `minSdk 26`.
- Контакт разработчика обязателен; пустое поле — причина отказа.
- Обещания в описании должны совпадать с тем, что видно на экране: у нас нет ни рекламы, ни
  покупок, ни аналитики — так и написано.
- Отклонённое приложение нельзя переопубликовать под другим аккаунтом без исправлений.

## О чём стоит помнить

- APK проверяется на эмуляторе прямо в CI: workflow `android` содержит job `smoke`,
  который ставит APK, запускает `ru.foxhunt.game/.MainActivity`, ждёт 25 секунд и снимает
  экран. Снимок успешного прогона — `ru-store/проверка-apk-эмулятор.png`: видно шапку,
  уровни, поле 10×10, строку «найдено 0/8 · ходы 0» и панель пеленга. В logcat нет ни
  ошибок Chromium, ни сетевых отказов.

- RuStore требует, чтобы APK был подписан; наш подписан схемой v2/v3.
- Для бесплатных приложений без покупок платёжные инструменты и самозанятость не нужны.
- Модерация не любит пустых обещаний: в описании не должно быть функций, которых нет.
  Поэтому про донат написано осторожно — «если захочется поддержать».
- Скриншоты снимались на 1080×1920; если консоль попросит другой размер, снимем заново
  тем же способом (эмуляция 360×640 при DPR 3).
